# Laira T. Hipolito – Digital Portfolio

 

A clean, responsive personal portfolio website built with vanilla **HTML**, **CSS**, and **JavaScript**.

 

## Project Structure

 

```

Portfolio/

├── index.html          # Main entry point

├── css/

│   └── style.css       # All styles (CSS custom properties, responsive design)

├── js/

│   └── main.js         # Scroll effects, mobile nav, form validation

└── README.md

```

 

## Sections

 

| Section | Description |

|---|---|

| Hero | Full-screen intro with name, title, and CTA buttons |

| About | Short bio and downloadable CV link |

| Skills | Three skill cards: Frontend, Backend, DevOps & Tools |

| Experience | Timeline of work history and education |

| Projects | Project cards with GitHub / Live demo links |

| Contact | Contact form + social links |

 

## Getting Started

 

Open `index.html` directly in your browser — no build step required.

 

For a live-reload dev experience, install the **Live Server** VS Code extension then right-click `index.html` → *Open with Live Server*.

 

## Customisation Checklist

 

- [ ] Replace placeholder text in **About** section with your actual bio

- [ ] Add your real photo — swap the `.about__avatar` div for an `<img>` tag

- [ ] Update **Skills** lists to match your actual tech stack

- [ ] Fill in **Experience** entries with your real job history

- [ ] Add your real **Projects** (title, description, GitHub URL, live URL)

- [ ] Replace social links in the **Contact** section (GitHub, LinkedIn, Email)

- [ ] Link the **Download CV** button to your actual CV file

- [ ] Connect the contact form to a real backend (e.g. [Formspree](https://formspree.io), [EmailJS](https://emailjs.com))
